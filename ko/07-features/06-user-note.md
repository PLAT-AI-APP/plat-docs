## 쓰는 법

- 대화방의 **채팅방 설정 → 유저 설정 → 유저노트**에서 작성하고 **저장**을 눌러요.
- 최대 **500자**까지 쓸 수 있어요.
- "잊으면 안 되는 중요한 내용, 추가하고 싶은 설정 등"을 적으면 돼요. 예를 들어 내 이름 부르는 방법, 지키고 싶은 약속, 반드시 지켜야 할 설정 같은 것이에요.
- 유저노트는 **채팅방마다 따로** 저장돼요.

## 함께 알아 두면 좋아요

- 유저노트에도 [이용 시 지켜야 할 기준](../10-policies/02-community-standards.md)이 적용돼요. AI의 안전 규칙을 피하게 만드는 용도로 쓰면 제한될 수 있어요.
- 유저노트 내용은 대화 내용과 함께 AI 제공사에 전달될 수 있어요. 화면 맨 아래 푸터의 개인정보처리방침을 확인해 주세요.
