---
title: 입력 글자 수 한도 한눈에 보기
summary: 입력할 수 있는 글자 수와 개수 제한을 한 번에 모았어요.
---

## 계정

| 항목 | 한도 |
| --- | --- |
| 닉네임 | 1\~20자, 특수문자 불가(이미 쓰이는 닉네임과 운영진으로 오인될 닉네임 불가) |
| 비밀번호 | 최소 8자, 특수문자 1개 이상 포함 (예: ! @ # \$) |
| 소개글 | 최대 100자 |
| 이메일 인증번호 | 6자리 |

## 대화

| 항목 | 한도 |
| --- | --- |
| 채팅 메시지 한 번 | 최대 4,000자 |
| 페르소나 | 최대 5개, 이름 최대 20자, 정보 최대 200자 |
| 유저노트 | 최대 500자 |
| 신고 상세 내용 | 최대 500자 (사유로 기타를 골랐다면 필수) |

## 캐릭터 만들기

| 항목 | 한도 |
| --- | --- |
| 제목 | 최대 20자 |
| 한 줄 소개 | 최대 20자 |
| 프롤로그 소개 | 최대 2,000자 |
| 캐릭터 이름 | 최대 20자 |
| 캐릭터 설명 | 최대 1,000자 |
| 상세 설정 | 최대 2,000자 |
| 에셋 | 최대 50개, 이름 최대 15자, 상황 최대 50자, 이미지 5MB 이하(jpg·png·webp) |
| 시나리오 | 최대 5개(최소 1개), 설명 최대 100자, 내용은 합쳐서 최대 5,000자 |
| 태그 | 1\~5개, 해시태그 제안의 이름은 최대 10자, 의견은 최대 200자 |
| 대표 이미지·프로필 이미지 | 5MB 이하, jpg·png·webp (대표 이미지는 1:1.3 비율) |
