title: 로그인과 비밀번호 재설정
summary: 로그인 방법과 비밀번호를 잊었을 때의 해결 방법을 안내해요.
---

## 1. 로그인 방법

- 이메일과 비밀번호로 로그인하거나, **카카오톡으로 시작하기** / **구글로 시작하기**로 로그인할 수 있어요.
- 가입할 때 쓴 방법으로 로그인해야 해요. 이미 가입된 이메일이라는 안내가 나오면 가입할 때 쓴 방법(이메일·구글·카카오)을 확인해 주세요.
- 로그인 후에는 보던 화면으로 돌아와요.

> **로그인 방법 : 우측 상단 로그인 → 이메일 입력 또는 카카오 / 구글 선택**

## 2. 비밀번호를 잊었어요

- 로그인 창의 **비밀번호를 잊으셨나요?**를 눌러요.
- 가입한 이메일을 입력하고 이메일 인증을 마치면 **비밀번호를 재설정**할 수 있어요.
- 재설정이 끝나면 새 비밀번호로 로그인해 주세요.
- 가입된 이메일이라면 인증번호가 발송돼요. 메일함을 확인해 주세요.

## 3. 로그인이 풀렸어요

- 오래 이용하지 않으면 **세션이 만료**될 수 있어요. 안내가 나오면 다시 로그인해 주세요.
- 로그인이 필요한 기능(대화, 찜, 댓글 등)을 로그인 없이 쓰려고 하면 로그인 안내가 나와요.
- 소셜 로그인이 실패하면 잠시 뒤 다시 시도해 주세요. 로그인 링크가 만료됐을 때도 처음부터 다시 로그인하면 돼요.

## 4. 로그아웃

- 우측 상단 프로필 메뉴에서 **로그아웃**을 누르면 돼요.
