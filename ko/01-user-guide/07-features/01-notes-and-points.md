summary: 이름이 비슷해서 헷갈리기 쉬운 노트와 수익 포인트, 한 번에 정리해 드릴게요.
---

| | 노트 | 수익 포인트 |
| --- | --- | --- |
| 뭔가요? | AI 캐릭터와 대화할 때 쓰는 이용권 | 내 캐릭터와 다른 이용자가 대화하면 쌓이는 크리에이터용 포인트 |
| 어떻게 받나요? | 충전, 가입·이벤트·프로모션 선물, 수익 포인트를 노트로 전환 | 다른 이용자가 내 캐릭터와 대화하면 적립 |
| 어디서 보나요? | 노트 충전 화면, 채팅방 설정의 보유 노트, 이용 내역 | 프로필 메뉴의 크리에이터 센터 |
| 어디에 쓰나요? | 대화 | 상품권 교환, 노트로 전환 |
| 언제까지 쓰나요? | 충전한 노트는 받은 날부터 5년 (무료 노트는 받은 방식에 따라 달라요) | 적립하고 5년 |
| 환불되나요? | 환불 조건에 맞는 유료 충전분만 돼요 ([환불 안내](../05-payment/03-refund.md)) | 환불되지 않아요 |

## 알아 두면 좋아요

- 노트는 **기간이 얼마 남지 않은 것부터** 알아서 쓰여요. 노트마다 언제까지 쓸 수 있는지는 [노트 사용 내역](02-note-history.md)에서 볼 수 있어요.
- 수익 포인트가 현금으로 얼마인지는 화면에 보여 드리지 않아요.
- 대화하다 노트가 모자라면 "노트가 부족해요"라고 알려 드려요. 충전하고 돌아오면 보내려던 말이 그대로 남아 있어요.
